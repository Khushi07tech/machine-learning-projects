## 📌 Repository Overview

This repository serves as a centralized portfolio of machine learning projects focused on building robust data pipelines, applying feature engineering, and conducting rigorous model evaluations. 

Each sub-directory contains an independent project complete with its own dataset handling, exploratory data analysis, algorithm selection, hyperparameter tuning, and visual performance reporting.
